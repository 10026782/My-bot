Security rule: no repository is adopted because of stars, popularity, awesome-list inclusion, or “open source”. Before a spike check license, maintainership, security policy, releases, dependency health/CVEs, secrets, network/process privileges, tenant isolation, auth, retention, telemetry, outbound calls, and supply-chain risk. MCP servers and agent skills require heightened scrutiny.
